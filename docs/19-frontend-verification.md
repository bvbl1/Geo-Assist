## Что проверено сквозными сценариями

1. **Гость и поиск.** Каталог и карточка, страницы по 20 мест, Back с сохранением фильтров, категория + тег + радиус, координаты и `distance_m`, отказ геолокации, отсутствие тайлов, ошибочная geo-ссылка, переход гостя к входу. Неизвестные API и assets возвращают 404, а не HTML.
2. **Аккаунт и личные действия.** Короткий пароль отклоняется до запроса; регистрация не создаёт cookie; вход создаёт HttpOnly/SameSite cookie и переживает refresh. Изменение имени и очистка категорий, favorite, оценки 5 → 4 → повтор 4 → удаление, select и история. Потеря ответа после сохранения select воспроизводится через браузерный interceptor: повтор не создаёт второе событие. Проверены один view за посещение, отсутствие лишнего rating event, запрет admin UI/API обычному пользователю, выход в соседней вкладке, смена аккаунта и утрата cookie.
3. **Администратор.** Создание места из формы, изменение, два редактора одной версии → 409, сохранение черновика, загрузка актуальной версии и успешное повторное редактирование. Подтверждённое удаление убирает место из каталога/избранного. В истории удалённое место сохраняется, его favorite/rating можно очистить.
4. **Ошибки.** Ошибка 503 и успешный повтор GET, 403 CSRF без ложного успеха, 429 с блокировкой кнопки на Retry-After.

Сбойные ответы и внешние тайлы подменяются только внутри тестов. Все обычные пользовательские операции выполняются настоящим backend и сохраняются в отдельной MongoDB E2E. В рабочем интерфейсе моков API нет. При исправлениях был повторён полный набор на окончательном Docker-образе.

## Границы проверки и текущего продукта

Автоматические E2E выполнены в Chromium; другие движки отдельно не проверялись. Режим Vite настроен и описан, основная сквозная приёмка выполнялась на production-сборке внутри Docker. Доступность внешнего OpenStreetMap не гарантируется приложением; при сбое подложки остаются список, API и ввод координат. Места Астаны — синтетические демоданные, а не проверенный справочник заведений.

Рекомендации, NL-запросы, мессенджер, маршруты по дорогам и фото мест относятся к следующим этапам. Текущие 19 бизнес-маршрутов доступны через сайт; структура и команды приведены в [руководстве 18](18-frontend-guide.md).
